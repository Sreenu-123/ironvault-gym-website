# 🏋️ IRONVAULT — Gym Website

**Built Beyond Limits. Train With Purpose.**

IRONVAULT is a premium, responsive gym website built with **React, Vite, and CSS**. Featuring a bold dark aesthetic, neon-lime accents, modern typography, and fitness-focused sections, this project is designed to be a customizable starting point for professional gym websites.

Built as an open-source frontend project for developers, designers, and fitness businesses.

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and Git before proceeding.

### 1. Clone the repository

```bash
git clone https://github.com/Sreenu-123/ironvault-gym-website.git
```

### 2. Navigate to the project

```bash
cd ironvault-gym-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for production

```bash
npm run build
```

The optimized production files will be generated in the `dist/` directory.
